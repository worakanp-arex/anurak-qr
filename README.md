# สร้างคิวอาร์โค้ด (ไม่มีโฆษณา)

เว็บหน้าเดียว ทำงานในเบราว์เซอร์ล้วน ไม่ต้องมีเซิร์ฟเวอร์ ไม่มีฐานข้อมูล

ธีม ANURAK KKU พร้อมโลโก้และภาพพื้นหลังโปร่งใส รองรับลิงก์/ข้อความ พร้อมเพย์ และ Wi-Fi

## พรีวิวพร้อมแก้ไข

ต้องมี Node.js จากนั้นเปิด Terminal ในโฟลเดอร์นี้แล้วรัน `node preview.cjs`
เปิด http://127.0.0.1:5500 เมื่อบันทึก HTML, CSS, JavaScript หรือรูปใน `assets` หน้าเว็บจะรีโหลดอัตโนมัติ

## เผยแพร่ผ่าน GitHub Pages

ใช้ branch `main` และโฟลเดอร์ `/ (root)` เป็น publishing source ใน Settings → Pages
ไฟล์ `.nojekyll` ทำให้ GitHub Pages เผยแพร่ไฟล์ HTML/CSS/JavaScript โดยตรง
เมื่อแก้เว็บแล้ว commit และ push ไปที่ `main` ระบบจะเผยแพร่เวอร์ชันใหม่ให้อัตโนมัติ

## อายุของคิวอาร์โค้ด

รูป QR เก็บข้อมูลที่กรอกโดยตรง ไม่มีการตั้งวันหมดอายุ และไม่ต้องเชื่อมต่อกลับมายังเว็บสร้าง QR เพื่อสแกน
หาก QR เก็บลิงก์ ลิงก์ปลายทางต้องยังใช้งานได้ หากปลายทางถูกลบหรือเปลี่ยน URL ต้องสร้าง QR ใหม่
การแก้ข้อมูลในเว็บสร้าง QR ไม่เปลี่ยนข้อมูลของรูป QR ที่บันทึกไปแล้ว

## ไฟล์ในโปรเจกต์

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | หน้าตาเว็บ: ปุ่ม ช่องกรอก ข้อความต่างๆ |
| `style.css` | สี ฟอนต์ ระยะห่าง (สีหลักอยู่บรรทัดบนสุดใน `:root`) |
| `script.js` | การสร้างคิวอาร์ พร้อมเพย์ Wi‑Fi และปุ่มคัดลอก |

## เปิดดูใน VS Code

1. เปิดโฟลเดอร์นี้ใน VS Code (File → Open Folder)
2. ติดตั้งส่วนขยาย **Live Server** (ของ Ritwick Dey)
3. คลิกขวาที่ `index.html` → **Open with Live Server**
4. แก้ไฟล์แล้วกดบันทึก หน้าเว็บจะรีเฟรชเอง

หรือดับเบิลคลิก `index.html` เปิดในเบราว์เซอร์ตรงๆ ก็ได้ แต่ต้องต่อเน็ตเพื่อโหลดฟอนต์และไลบรารีคิวอาร์

## จุดที่แก้บ่อย

- **เปลี่ยนสีธีม**: `style.css` แก้ `--accent` ใน `:root` (ธีมสว่าง) และในบล็อก dark (ธีมมืด)
- **เปลี่ยนค่าตัวอย่างตอนเปิดหน้า**: `index.html` แก้ข้อความใน `<textarea id="text">`, `value` ของ `ppId`, `ssid`, `wpass`
- **ตั้งเบอร์พร้อมเพย์ของร้านไว้เลย**: แก้ `value="0812345678"` ใน `index.html`
- **ความละเอียดรูป**: `script.js` ค้นหา `1024` (ขนาดรูปเป็นพิกเซลโดยประมาณ)
- **ปุ่มดาวน์โหลด PNG**: เมื่ออัปขึ้นเว็บเองแล้ว ใส่ลิงก์ดาวน์โหลดได้ ดูหัวข้อข้างล่าง

### เพิ่มปุ่มดาวน์โหลด (ใช้ได้เมื่อเปิดจากเว็บของคุณเอง)

ใน `index.html` ใต้ปุ่ม "คัดลอกข้อมูลในโค้ด" เพิ่ม:

```html
<a class="act" id="download" download="qrcode.png" href="#">ดาวน์โหลด PNG</a>
```

ใน `script.js` ในฟังก์ชัน `render()` ต่อจากบรรทัด `$('qrImg').src = ...` เพิ่ม:

```js
$('download').href = $('qrImg').src;
```

## อัปขึ้นเว็บให้คนอื่นใช้ (ฟรี)

**แบบง่ายสุด – Netlify Drop**
1. ไปที่ app.netlify.com/drop
2. ลากโฟลเดอร์นี้ทั้งโฟลเดอร์ไปวาง
3. ได้ลิงก์ทันที (สมัครบัญชีฟรีเพื่อเก็บเว็บไว้ถาวรและตั้งชื่อลิงก์)

**แบบ GitHub Pages** (เหมาะถ้าจะแก้บ่อย)
1. สร้าง repository ใหม่ใน GitHub แล้วอัปโหลด 3 ไฟล์นี้
2. Settings → Pages → Source: เลือก branch `main` แล้วกด Save
3. รอสักครู่ จะได้ลิงก์ `https://ชื่อผู้ใช้.github.io/ชื่อrepo/`

คนใช้จำนวนน้อยถึงปานกลางใช้ฟรีได้สบาย เพราะเว็บไม่มีเซิร์ฟเวอร์ประมวลผล ทุกอย่างคำนวณในเครื่องของคนใช้เอง

## หมายเหตุพร้อมเพย์

โค้ดสร้างตามมาตรฐาน EMVCo (Thai QR Payment) ก่อนใช้รับเงินจริง ให้สแกนทดสอบด้วยแอปธนาคารของคุณเองก่อนหนึ่งครั้ง แล้วดูว่าชื่อผู้รับขึ้นถูกต้อง
